# TemplateLove
Replacing by a template from an array

Легковесная PHP-функция для шаблонизации строк и файлов. Поддерживает простую подстановку переменных, доступ к многомерным массивам через разделитель и рекурсивную обработку списков.
Особенности
Гибкие источники: В качестве шаблона можно передать как строку, так и путь к файлу.
Deep Access: Получение данных из глубоко вложенных массивов через синтаксис key1|key2|key3.
Обработка списков: Автоматический перебор массивов для генерации повторяющихся блоков (например, строк таблиц или элементов списка).
Кастомные регулярные выражения: Возможность переопределить формат меток (по умолчанию используются квадратные скобки [...]).
Установка
Просто скопируйте функцию template() в свой проект или подключите файл с ней.

# Использование
1. Простая подстановка
php
$data = ['name' => 'Иван', 'role' => 'Админ'];
$tpl = "Привет, [name]! Твоя роль: [role].";

echo template($data, $tpl); 
// Результат: Привет, Иван! Твоя роль: Админ.
Используйте код с осторожностью.

2. Вложенные массивы
Используйте символ | для прохода вглубь массива.
php
$data = [
    'user' => [
        'profile' => ['id' => 505]
    ]
];
$tpl = "ID пользователя: [user|profile|id]";

echo template($data, $tpl); 
// Результат: ID пользователя: 505
Используйте код с осторожностью.

3. Работа со списками (Циклы)
Для обработки массивов используйте специальный синтаксис: [название_массива|(шаблон_элемента)]. Внутри круглых скобок для обращения к полям элементов используйте фигурные скобки {...}.
php
$data = [
    'users' => [
        ['name' => 'Алексей'],
        ['name' => 'Мария']
    ]
];
$tpl = "Список: [users|(<li>{name}</li>)]";

echo template($data, $tpl); 
// Результат: Список: <li>Алексей</li><li>Мария</li>

4. Использование внешних файлов
Если в параметр $template передать путь к файлу, функция автоматически загрузит его содержимое.
php
echo template($data, 'templates/user_profile.html');

# Параметры функции
php
function template($array, $template, $regexp)
$array (array): Ассоциативный массив с данными.
$template (string): Строка шаблона или путь к файлу шаблона.
$regexp (string|null): Регулярное выражение для поиска меток. По умолчанию: /\[.*?]/s.

# Обработка ошибок
Если переменная не найдена в массиве, функция вернет текст Error: имя_переменной.
Если структура массива для цикла некорректна, вернет Error: rps!.
