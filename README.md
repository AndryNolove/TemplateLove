# TemplateLove v2

Небольшой типизированный PHP-рендерер для простых шаблонов строк и HTML.

## Возможности

- `[name]` — подстановка значения;
- `[user|profile|id]` — доступ к вложенным массивам;
- `[%users%<li>{name}</li>]` — повторение блока для списка;
- загрузка шаблона из файла;
- безопасное HTML-экранирование значений;
- понятные исключения при ошибках шаблона или данных.

## Установка

Скопируйте `template.php` в проект и подключите его:

```php
require_once __DIR__ . '/template.php';
```

## Использование

```php
$data = [
    'title' => 'Привет',
    'users' => [
        ['name' => 'Анна'],
        ['name' => 'Иван'],
    ],
];

echo template($data, '<h1>[title]</h1>[%users%<p>{name}</p>]', null, true);
```

Четвёртый аргумент включает `htmlspecialchars()` для подставляемых значений. Используйте его для пользовательских данных.

Шаблон можно загрузить из файла:

```php
echo template($data, __DIR__ . '/templates/users.html');
```

Для ограничения чтения файлов укажите корневую директорию шаблонов пятым аргументом:

```php
echo template($data, $path, null, true, __DIR__ . '/templates');
```

## Ошибки

Отсутствующий ключ оставляется как `Error: key`. Некорректный цикл, массив вместо скалярного значения и неверный regexp приводят к исключению.

## Требования

- PHP 8.0 или новее;
- UTF-8.
